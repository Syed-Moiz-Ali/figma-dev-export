# Support

Thanks for using Dev Export for Figma.

## Where to ask for help

Please use this repository's **GitHub Issues** for support, bug reports, and feature requests.

Before opening an issue:

1. Update to the latest published plugin version.
2. Re-run the export with fewer selected screens.
3. Keep **Figma CSS snapshot** disabled unless you specifically need it.
4. If a package is too large, reduce the per-screen asset budget or split the export into smaller batches.

## What to include in a bug report

- Figma desktop operating system
- Approximate number of selected screens
- Approximate layer count if known
- Export settings used
- What you expected
- What happened instead
- A screenshot of the plugin UI if useful

**Do not upload private or confidential design files unless you are comfortable sharing them publicly.** A reproduction file with non-sensitive placeholder content is preferred.

## Response expectations

Issues are reviewed as time permits. Security-sensitive reports should follow [SECURITY.md](SECURITY.md) instead of being posted publicly.
