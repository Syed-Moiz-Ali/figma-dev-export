# Frontend Handoff Studio

Frontend Handoff Studio is a Figma plugin that exports selected design screens into organized, implementation-ready frontend handoff packages.

## What it exports

- Structured screen JSON with layout, typography, color, spacing, constraints, and metadata
- 2× screen previews
- Exact SVG vector assets and PNG inspection copies
- Composed SVG + PNG decorative graphics
- Original raster assets and rendered PNG representations
- Per-screen asset manifests and a visual asset catalog
- One master package for multi-screen exports

## Privacy-first by design

The plugin performs export processing locally inside Figma's plugin runtime. It declares **no external network access**, uses **no analytics**, requires **no account**, and does not upload design content to the developer or third parties.

See [Privacy Policy](PRIVACY.md) and [Security](SECURITY.md).

## Support

For bugs, questions, or feature requests, use [GitHub Issues](../../issues) after checking [SUPPORT.md](SUPPORT.md).

## Supported implementation targets

The exported handoff is framework-neutral and can be used with React, Next.js, Vue, Nuxt, Angular, Svelte, HTML/CSS, Flutter, React Native, SwiftUI, Jetpack Compose, and other frontend stacks.
