# Getting started

1. Select one or more complete top-level frames in Figma Design.
2. Run **Frontend Handoff Studio**.
3. Review the selected screen list.
4. Keep the recommended export options enabled.
5. Click **Generate handoff package**.
6. Click **Download ZIP**.

Each exported screen includes structured JSON, a visual preview, and its own asset folder. Multi-screen exports also include a package manifest.

## Recommended settings

- Screen previews: on
- Exact vectors: on
- PNG copy for every asset: on
- Composed graphics: on
- Raster images: on
- Variables: on
- Figma CSS: off unless specifically useful
- Hidden layers: off
- Layer limit: 4000
- Asset budget: 40 MB per screen

## Privacy

The plugin does not make external network requests. See [Privacy](../PRIVACY.md).
